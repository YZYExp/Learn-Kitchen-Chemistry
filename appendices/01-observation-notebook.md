# 附录一：厨房观察手册

这份手册帮助组织比较，不是食安验证方案。每次只取少量样品，容器标记“观察用”，结束后及时清理。不要为了等待结果而让易腐食物长时间放置，不试吃观察样品。涉及加热的项目沿用正常烹饪，不增加密闭、干烧或高温油糖操作。

## 一页记录，保留完整条件

| 记录项 | 写到什么程度 |
|---|---|
| 问题 | “这次搅拌会不会缩短糖粒消失的时间”，而非泛泛的“糖的实验” |
| 样品 | 同一批原料、相近颗粒或厚度，记录质量和用水量 |
| 改变项 | 每轮只改变一个主要条件 |
| 保持项 | 容器、水量、起始温度、等待时间等 |
| 观察对象 | 可见颗粒、分层高度、流动速度、颜色或质量 |
| 结果 | 原始记录与照片，不预先写“成功/失败” |
| 解释 | 哪个机制能解释，哪些替代解释尚未排除 |
| 下一轮 | 只补一个最关键的比较 |

## 从容易控制的现象开始

**糖的溶解。** 两杯等量同温水，等量同批白糖，一杯搅拌一杯静置。记录可见糖粒消失的时间。这一轮比较的是溶解速度，不是最大溶解量；杯子更清澈也不能证明糖的化学身份已经改变。详见第2—3章。

**油水分散。** 在两个相同的小透明容器中放等量油和水，一份轻轻搅动，另一份充分搅动；观察静置后的变化。若再比较加入少量芥末的情况，另开一轮记录。芥末可能同时改变界面稳定性与连续相黏度，不把“加了就稳定”自动归为单一作用。详见第8章。

**勾芡前的分散。** 在正常烹饪中观察冷水淀粉浆倒入热汤后的变化，记录加入和搅拌方式。不要把干淀粉直接投入滚汤的结块，误判成淀粉没有增稠能力；外层先糊化会阻碍水进入团块。不要尝生淀粉或生面粉。详见第10章。

**切面颜色。** 用同一个苹果的相近切片，比较不处理与涂少量柠檬汁后的短时颜色变化。两份保持厚度、光照和拍照角度接近。柠檬汁同时带来酸度和其他成分，不能凭这一轮区分每个成分的贡献；更不能用变色快慢评价保存安全。详见第15—17章。

**面包质地。** 使用正常购买、在保质与保存条件内的面包，观察包装完整程度、放置温度与口感变化的关联。不要主动培养霉菌，也不以“看不见霉”证明安全。若只凭手感无法分清失水与淀粉回生，明确记为两种可能，而不是任选一个答案。详见第10、12、22章。

## 三个常见的推理陷阱

一次改变好几个条件，会让结果失去归因能力；用不同原料替代相同原料，会把品种和组成差异一起带进来；只记录符合预期的样品，会使解释看起来比实际可靠。家庭比较允许不完美，但应把这些限制写出来。

同一个现象也可能有多条路。黏稠可以来自颗粒膨胀、分散相增多、胶体网络或水分减少；冒泡可以来自沸腾、溶解气体逸出或反应生成气体。记录现象后，再回到相应章节寻找可检验的区分方法。
