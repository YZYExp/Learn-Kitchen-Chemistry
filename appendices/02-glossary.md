# 附录二：把术语放回厨房

简明含义用于回查；具体条件、例子和来源见相应章节。描述状态、变化速度与最终组成，是三种不同任务。

| 术语 | 怎样理解 | 章节 |
|---|---|---|
| 溶解 | 溶质进入溶剂形成分子或离子尺度的混合 | 2 |
| 熔化 | 固体变成液体，未必需要溶剂 | 2、14 |
| 溶解度 | 给定条件下能溶多少，不是多久溶完 | 2 |
| 浓度 | 溶质相对一定量溶液或溶剂的多少，要注明计量方式 | 3 |
| 扩散 | 粒子热运动引起的净分布变化，区别于搅拌的整体流动 | 2、20 |
| 水活度 | 水的热力学状态指标，不能当作含水率 | 3、23 |
| pH | 水溶液的酸碱状态指标，不是所有酸的总量 | 4 |
| 缓冲 | 体系抵抗少量酸碱引起pH变化的能力 | 4 |
| 蒸发 | 从液体表面进入气相，可在沸腾前发生 | 2、5 |
| 沸腾 | 适当条件下液体内部持续形成蒸气泡 | 2、6 |
| 凝结 | 气体变回液体，蒸汽遇较冷表面可形成水滴 | 6 |
| 传导 | 能量通过物质内相互作用传递 | 5、26 |
| 对流 | 流体整体运动参与热量传递 | 5 |
| 热辐射 | 电磁辐射传递能量，无需接触 | 5、26 |
| 乳化 | 一种不相混溶液体以液滴分散进另一液体 | 8 |
| 连续相 | 形成连续背景的部分，不能只凭含量猜测 | 8 |
| 聚并 | 液滴合成更大液滴，区别于整体上浮 | 8 |
| 泡沫 | 气体以气泡形式分散于液体或固体体系 | 9 |
| 黏度 | 抵抗流动变形的性质之一，不等于是否成胶 | 9、13 |
| 糊化 | 适当水热条件下淀粉失去部分有序结构并膨胀等变化 | 10 |
| 回生 | 糊化后淀粉链重新缔合并形成一定有序结构 | 10 |
| 变性 | 蛋白质原有空间结构改变，通常不等于主链全断 | 11 |
| 水解 | 水参与化学键断裂，与单纯结构展开不同 | 11、17 |
| 面筋 | 小麦相关蛋白在水与加工作用下形成的黏弹网络 | 12 |
| 凝胶 | 连续网络限制液体流动，成胶条件随材料改变 | 13 |
| 晶体 | 有序排列的固体结构，同一物质可能有不同晶型 | 14 |
| 美拉德反应 | 还原糖与含氨基成分参与的一组复杂反应 | 15 |
| 焦糖化 | 糖本身受热转化，不要求必须有蛋白质 | 15 |
| 酶 | 具有催化功能的生物分子，不是微生物别名 | 17 |
| 风味 | 味觉、嗅觉和多种口腔感觉共同参与的体验 | 19 |
| 萃取 | 成分从原料转入所用介质，受多项条件影响 | 20 |
| 交叉污染 | 污染经手、器具、汁液或表面等转移 | 24 |
| 清洁与消毒 | 移除污物等与在规定条件下减少或灭活微生物 | 25 |
| 表面活性剂 | 改变界面行为，许多洗涤剂用它帮助去污 | 25 |
| 工艺功能 | 成分在加工中的作用，不等同营养价值 | 27 |
