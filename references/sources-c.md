# 第15—21章来源与核查记录

核查日期：2026-10-26。正文为原创中文讲解，不作来源的逐句翻译；引用紧邻对应知识点，章末保留本章资料。下表用于编辑核查，不替代章内引用。

| 15 褐变 | [ACS：美拉德反应](https://cen.acs.org/articles/89/i47/Maillard-Reaction.html)；[美国烘焙学会：美拉德反应](https://asbe.org/article/maillard-reaction/)；[美国烘焙学会：焦糖化](https://asbe.org/article/caramelization/)；[ACS：减缓苹果褐变](https://www.acs.org/education/celebrating-chemistry-editions/2021-ncw/slowing-apple-browning.html) | 区分氨基化合物/还原糖反应、糖的热反应与酶促褐变；不设统一温度开关，不从颜色量化机制比例。 |
| 16 蔬果 | [FAO：果蔬结构与加工变化](https://www.fao.org/4/V5030E/V5030E06.HTM)；[伊利诺伊大学推广部：植物色素](https://extension.illinois.edu/blogs/simply-nutritious-quick-and-delicious/2026-04-17-power-plant-pigments)；[ACS：紫甘蓝指示剂](https://www.acs.org/education/activities/red-cabbage-indicator.html)；[明尼苏达大学：蔬菜焯水](https://extension.umn.edu/food/preparing/cooking-at-home/food-preservation/blanching-vegetables) | 结构与颜色分开讨论；花青素不代表所有红色色素；焯水时长必须按具体蔬菜验证指南，书内不自拟保存参数。 |
| 17 酶 | [RSC：酶与果冻](https://edu.rsc.org/resources/enzymes-and-jellies/815.article)；[麦吉尔大学：鲜菠萝与明胶](https://www.mcgill.ca/oss/article/general-science-you-asked/why-cant-i-use-fresh-pineapple-make-jell-o)；[Imai等2002洋葱催泪酶原始论文](https://www.nature.com/articles/419685a)；[USDA：焯水与酶活性](https://ask.fsis.usda.gov/article/What-is-blanching-and-how-does-it-relate-to-enzyme-activity-when-freezing-food) | 明胶水解不等于蛋白质展开；洋葱挥发的是产物而非酶蛋白；不声称酸果汁可杀灭生肉病原体。Nature原始论文搜索元数据与机制摘要可取，全文抓取遇到出版社重定向，未声称全文已读取。 |
| 18 发酵 | [OpenStax《微生物学》8.4](https://openstax.org/books/microbiology/pages/8-4-fermentation)；[佛罗里达大学：酸奶](https://ask.ifas.ufl.edu/publication/FS468)；[NCHFP：发酵一般信息](https://nchfp.uga.edu/how/ferment/general-information-on-fermenting/general-information-on-fermenting/)；[红茶模型氧化实验原始研究](https://pubmed.ncbi.nlm.nih.gov/25051300/) | 区分食品行业广义发酵与生化狭义发酵；醋酸氧化需氧；红茶关键酶促氧化不等同酸奶发酵；不给自创盐比例、时间和罐藏配方；产气/酸味均不能证明安全。 |
| 19 风味 | [NIDCD：味觉](https://www.nidcd.nih.gov/health/taste-disorders)；[NIDCD：嗅觉](https://www.nidcd.nih.gov/health/smell-disorders)；[诺贝尔奖科学背景](https://www.nobelprize.org/prizes/medicine/2021/advanced-information/)；[2024茶涩味口腔处理原始研究](https://pubmed.ncbi.nlm.nih.gov/38329502/) | 舌头各区域并非独占基本味；鼻后嗅觉与味觉区分；辣、凉、涩不简单列为基本味；不从好闻推定安全。 |
| 20 萃取 | [全浸泡咖啡平衡模型原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7994670/)；[Batali等2020温度控制原始研究](https://www.nature.com/articles/s41598-020-73341-4)；[红茶涩味成分原始研究](https://pubs.acs.org/doi/10.1021/jf049802u)；[探索馆：肉与胶原](https://annex.exploratorium.edu/cooking/meat/INT-what-makes-juicy.html) | 饮料浓度≠萃取率；Batali等结论限于其滴滤、温度范围、浓度和萃取控制条件，不外推“温度无用”；高汤并非纯萃取；颜色/浑浊不作为成分测量。 |
| 21 香辛料 | [ACS：大蒜素](https://www.acs.org/molecule-of-the-week/archive/a/allicin.html)；[ACS：葱属化学讲座](https://www.acs.org/content/dam/acsorg/acs-webinars/2014/slides/2014-09-11-alliums-final.pdf)；[ACS：姜酚、姜烯酚、姜酮](https://www.acs.org/molecule-of-the-week/archive/g/gingerol.html)；[诺贝尔奖科学背景](https://www.nobelprize.org/prizes/medicine/2021/advanced-information/)；[Hagura等2013花椒感觉原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3779329/) | 大蒜破碎后会新生成含硫物质；姜的加工不只是失水；辣椒刺激与香气区分；花椒研究为感觉匹配，不描述成嘴唇实际振动、不普遍外推精确频率。 |
